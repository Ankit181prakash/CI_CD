# CI/CD Pipeline with GitHub Actions

This project is a simple demonstration of a CI/CD pipeline using GitHub Actions.

## Project Overview

A small Python program is used to test the CI/CD workflow.

The pipeline automatically runs whenever new code is pushed to the GitHub repository.

## Technologies Used

- Python
- Git
- GitHub
- GitHub Actions
- YAML

## CI/CD Workflow

1. Developer writes or modifies Python code.
2. Changes are committed using Git.
3. Code is pushed to GitHub.
4. GitHub Actions automatically starts the pipeline.
5. Python environment is configured.
6. Required dependencies are installed.
7. Python code is executed.
8. Tests are executed.
9. Pipeline reports success or failure.
10. Successful changes are ready for deployment.

## Objective

The main objective of this project is to understand how Continuous Integration and Continuous Deployment can be implemented using GitHub Actions.
